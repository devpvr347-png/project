MediCare – Pharmacy Management System 💊

A web-based Pharmacy Management System built using HTML, CSS and JavaScript to make pharmacy operations easier, faster and more organized.

About the Project

MediCare is a frontend-based pharmacy management web application designed to help manage daily pharmacy activities through a simple and user-friendly interface.

It provides an organized platform for managing medicines, monitoring stock, handling billing and maintaining pharmacy-related records.

Features

- User-Friendly Interface
- Merchant Registration and Login UI
- Admin Dashboard UI
- Medicine Inventory Management
- Add, Edit and Search Medicines
- Stock Management
- Expiry Date Tracking
- Sales and Billing Interface
- Customer Records
- Supplier Management
- Responsive Design

Technology Stack

- HTML5 – Structure of the website
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactivity
- VS Code – Development Environment
- Git & GitHub – Version Control

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. You can also use the Live Server extension in VS Code.

Project Objective

The main objective of MediCare is to provide a simple digital interface for pharmacy management, reduce manual effort and make everyday pharmacy operations more organized and efficient.
